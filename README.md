#  TechNews Today 

Projeto desenvolvido como parte de uma atividade prática no curso de **Desenvolvimento de Sistemas do SENAI**. O objetivo principal é construir um portal moderno de notícias sobre tecnologia utilizando **HTML5 semântico** e estilização avançada com **CSS3**.

<br><br>

## Demonstração

<br><br>

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica utilizando tags como `<header>`, `<main>`, `<article>`, `<section>`, `<details>`, `<form>` e `<footer>`.
* **CSS3:** Estilização moderna utilizando variáveis CSS, layout responsivo com CSS Grid, animações de *hover* e efeito *glassmorphism*.

<br><br>

##  Funcionalidades

* **Cabeçalho com Efeito Glassmorphism:** Layout fixo com visual moderno e efeito translúcido.
* **Artigo em Destaque:** Card interativo que inclui o elemento `<details>` para expandir e ler mais informações.
* **Mídia Incorporada:** Seção dedicada com suporte a exibição de vídeos do YouTube via `<iframe>`.
* **Formulário de Newsletter:** Campos estruturados para captura de e-mail, seleção de áreas de interesse, *checkbox* de termos de uso e botão customizado com gradiente.
* **Design Responsivo:** Adaptação automática do layout para dispositivos móveis e desktops utilizando *Media Queries*.

<br><br>
                    
##  Aprendizados (SENAI)

Nesta atividade foram praticados conceitos como:

* **HTML5 Semântico:** Boas práticas na construção de páginas web com marcas semânticas.
* **Organização em CSS:** Estruturação e manutenção de arquivos de estilos CSS.
* **Layouts Modernos:** Técnicas de responsividade e alinhamento usando **CSS Grid** e **Flexbox**.
* **Interatividade e Estilo:** Estilização de formulários e estados de interação (`:hover`, `transform`, variáveis CSS).
